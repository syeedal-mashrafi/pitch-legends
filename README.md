# Pitch Legends ⚽

A mobile-style football game that runs entirely in the browser. Pick your squad, kick off, and play a full match with touch controls or a keyboard.

**Play it:** https://syeedal-mashrafi.github.io/pitch-legends/

## Features

- **Squad screen** with player cards and ratings in a 4-3-3 Holding formation, plus Home/Away views
- **Three opponent levels** (Amateur, Pro, Legendary) and three match lengths (4, 6 or 10 minutes)
- **Full match** with two halves, kick-offs, throw-ins, corners, goal kicks, keeper saves and half-time/full-time stats
- **Touch controls**: joystick plus Pass, Through, Shoot and Sprint & Skill buttons
- **Defence mode**: Switch, 2nd Def, Slide and Sprint & Tackle, plus an AUTO defend joystick
- **Swipe moves**: lofted passes, chip, driven and finesse shots, and skill moves
- **Live commentary** as text and voice
- **Original anthem**, "Cholo Warriors," with Bangla lyrics
- **Crowd sound** and referee whistles
- **Built-in How to play manual**

## Controls

| Key | With the ball | Without the ball |
|---|---|---|
| WASD / Arrows | Move | Move |
| J | Pass | Switch player |
| K | Through ball | 2nd defender (hold) |
| L / Space | Shoot | Slide tackle |
| Shift | Sprint | Sprint & tackle |
| U / I | Lofted pass / lofted through | – |
| O | Chip shot | – |
| E | Skill move | – |
| Enter | Kick off | Kick off |
| Esc | Pause | Pause |

On touch screens, swipe a button instead of tapping it:

| Button | Swipe | Move |
|---|---|---|
| Pass / Through | Up | Lofted ball |
| Shoot | Up | Chip shot |
| Shoot | Down | Driven shot |
| Shoot | Left or right | Finesse shot |
| Sprint & Skill | Any direction | Skill move |

## Rules

- A goal counts when the ball crosses the line between the posts and under the crossbar.
- When the ball goes over a sideline, the team that did not touch it last takes a throw-in.
- If a defender touches the ball last before it goes over their own goal line, the attackers get a corner. If an attacker touches it last, the defenders get a goal kick.
- This version has no offside, fouls, cards or extra time.

## Built with

HTML, CSS and JavaScript in a single file. It uses Canvas for the pitch, the Web Audio API for the music and crowd sound, and the Web Speech API for commentary. It has no build step and no dependencies.

## Run it locally

Download `index.html` and open it in any modern browser.
